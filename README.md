## 🌎 Data for the Environment

> *Pipelines that don't just move data — they help protect a forest.*

I'm building a **geospatial data warehouse** designed to detect and track illegal deforestation, integrating satellite imagery, remote-sensing feeds, and public environmental datasets into a single, queryable source of truth. The goal: turn raw geodata into fast, reliable alerts that support real enforcement action — less time reconciling shapefiles, more time acting on what the data already knows.
